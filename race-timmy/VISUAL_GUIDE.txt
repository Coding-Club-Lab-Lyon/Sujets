                         VISUAL ELEMENTS
═══════════════════════════════════════════════════════════════════════════

🏎️  THE CAR (TIMMY)
    • Color: Blue (normal) / Red (crashed)
    • Shape: 3D box with visible orientation
    • Size: About 1.5 units
    • Position: Follows your control commands

═══════════════════════════════════════════════════════════════════════════

🟢 LIDAR RAYS (Green Lines)
    • 91 rays in a 90-degree arc
    • Emanate from front of car
    • Length shows distance to wall
    • Updates in real-time
    • Visual debugging tool

    Example:
         ╱│╲
        ╱ │ ╲      ← Rays spread out
       ╱  │  ╲
      ╱   │   ╲
         🏎️

⬜ START/FINISH LINE (White)
    • Vertical white line
    • Located at bottom of track
    • Cross it to complete lap
    • Visible from distance

    • Oval shape

═══════════════════════════════════════════════════════════════════════════
                         GAME STATES
═══════════════════════════════════════════════════════════════════════════

🟦 NORMAL STATE
   • Car is blue
   • Timer running
   • LIDAR rays visible
   • Car responds to controls

   Display: "Time: 12.34s | Speed: 15.2"

───────────────────────────────────────────────────────────────────────────

🟥 CRASHED STATE
   • Car turns red
   • Timer stops
   • Car stops moving
   • Need to restart

   Display: "CRASHED! Press R to restart"

───────────────────────────────────────────────────────────────────────────

⏸️  PAUSED STATE
   • Everything frozen
   • Timer paused
   • Yellow text
   • Press SPACE to resume

   Display: "PAUSED - Press SPACE to continue"

───────────────────────────────────────────────────────────────────────────

🏁 LAP COMPLETE
   • Green text
   • Final time shown
   • Auto-paused
   • Can restart for better time

   Display: "LAP COMPLETE! Time: 23.45s"

═══════════════════════════════════════════════════════════════════════════
                         WHAT TO WATCH FOR
═══════════════════════════════════════════════════════════════════════════

✓ GOOD SIGNS:
  • Car moving smoothly
  • LIDAR rays balanced left/right
  • Consistent speed
  • Smooth steering changes
  • Car stays centered in track

✗ WARNING SIGNS:
  • Car zigzagging
  • Very short LIDAR rays
  • Sudden speed changes
  • Heading toward wall
  • Spinning in circles

═══════════════════════════════════════════════════════════════════════════
                         DEBUGGING VISUALLY
═══════════════════════════════════════════════════════════════════════════

Use the LIDAR rays to debug:

1. PAUSE (SPACE) when something goes wrong
2. Look at the LIDAR rays:
   • Are they balanced?
   • Which direction has more space?
   • Is there an obstacle ahead?
3. Think about what your code should do
4. Resume and test

Example Scenarios:

Scenario 1: Car turning right when it should go straight
  Look: LIDAR rays are balanced
  Problem: Steering logic is wrong
  Fix: Check left/right comparison

Scenario 2: Car crashing into walls
  Look: Short rays on one side
  Problem: Not detecting wall soon enough
  Fix: Increase detection distance

Scenario 3: Car going too fast
  Look: Rays getting short quickly
  Problem: Not slowing down for turns
  Fix: Add speed control based on front distance
