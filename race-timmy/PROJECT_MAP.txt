🔧 TECHNICAL REQUIREMENTS

Software:
  • Python 3.8 or higher
  • pip (Python package manager)
  • OpenGL support (usually built-in)

Python Packages:
  • pygame >= 2.5.0
  • PyOpenGL >= 3.1.6
  • PyOpenGL-accelerate >= 3.1.6
  • numpy >= 1.24.0

System:
  • Works on: Windows, macOS, Linux
  • Disk space: ~100 MB
  • RAM: 512 MB minimum
  • Graphics: Any GPU with OpenGL support
